Actual authority retained:

- For catalogue-backed output, export calls the existing
  generated_module_scope/module_scope_in and compiler_context selector. It keeps
  the actual selected catalogue's scope/declaration/hygiene/expansion-ancestry
  allocation roots, module-scope map and actual GeneratedItems output. It preserves

  original provider/before anchor and inherited source/generated module outers.
  No original source body is fabricated or rewritten.
- Plain item output often has no catalogue. The existing header-plan condition
  deciding whether a macro catalogue is required is factored as
  requires_macro_catalog without changing its logic. Only where this condition
  proves no module macro/import/call/module-source/attribute facts, and actual
  complete_without_macro_bindings succeeds in the ordinary completion branch,
  an opaque CompletedEmptyBoundary is retained. It contains actual issued call,
  record, original source ordinal/scope and insertion range, with checked retained
  metadata. Export joins this receipt to the actual record/GeneratedItems/current

  not assume that a function output implies an empty scope. An inline module with

  remain a separate lexical demand. Failed/incomplete catalogue preparation cannot
  mint this proof. No second Type-absence resolver or unconditional catalogue
