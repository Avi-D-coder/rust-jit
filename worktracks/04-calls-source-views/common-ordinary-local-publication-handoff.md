## Implemented source/API and separate review

`Database::publish_ordinary_local_function(&OrdinaryLocalAdmission)` is now in
new unregistered memo child `db/ordinary_local_inputs.rs`. Root adds only the
normal memo child hook when integrating; this worker edited no DB hooks/provider
or ordinary engine call sites. It requires coordinator/active run/exact issuance
revision, the actual prepared relevant-input guard, actual parent/source rows,
opaque current parent environment and exact LocalDeclarationOwner. It compares
all actual child source/header/context/body values plus their stamps. Missing
cold metadata cannot be reconstructed. Only one missing DefinitionBody may be
inserted after checked metadata/quota/revision preflight; source_revision,
environment, source/header/context/owner and active-run state are untouched.

An identical existing body is idempotent only with a current freshly prepared
proof; the old issuance cannot silently refresh after any derived revision.
After first publication, the original proof's relevant-input guard remains the
callable guard: body availability is deliberately not a signature/Value39 lookup
dependency. Its existing callable() consumes exact published rows and constructs
the same SourceCallable. Existing root local_source_contract source/body joins
handle both held legacy and ordinary proofs. No public proof constructor, new
input key/value/query, retained registry or executable evaluator is introduced.

The source proof alone is not a VM-current-position witness. Root must match
site/body against the actual entered call frame before using this publication.
Normal contracts, body preparation, execution/continuation/suspension/cleanup
and callable parent-root accounting still require root integration/evidence.
The old numeric/original-only publisher is unchanged and held until replaced
production consumers and all required removal/route evidence exist.
