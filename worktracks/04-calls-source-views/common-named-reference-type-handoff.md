schema fingerprint. Its source term and runtime key are retained separately from
name-site authority. It does not reconstruct source from a descriptor, force
fields, lower a body, run a trait/borrow checker or execute a macro.

then selects source types with this same resolver. Nongeneric nominal source
hints are concrete source templates with descriptor None. The ordinary by-value
runtime contract still returns NeedType: public ArgumentType(TypeId) is insufficient
runtime authority. The next shared prerequisite is an opaque ordinary parameter

actual owning values/store before entry. This component does not pretend that
source-template preparation closes that gap.
