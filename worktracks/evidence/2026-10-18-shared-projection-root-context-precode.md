# One indexed shared-borrow context for temporary and const roots

LOCAL-044, T032/T054 E005/E007. Unchanged static-ref-to-const-array-element.rs includes both &(42,).0 and &ALL_THE_NUMS[i]. Actual V33 fails the former after return; V34 literal projection fix is source-reviewed, but no runtimes ran (missing module selectors), and V35 failed compilation. Source inspection proves the latter root still lacks promotion: path_is_shared_borrow_operand only recognizes an immediate Ref parent, so its Index parent returns false and the constant becomes a fresh frame-owned aggregate. This second-path diagnosis is source-only, not a recorded runtime failure.

Replace both context predicates with actual immutable BodyIndex metadata, produced from each actual AST node during the existing canonical indexing pass. Mark only Field/Index nodes as projection-base edges and only shared, non-raw RefExpr as shared-borrow roots; preserve existing parenthesized metadata. BodyIndex::shared_borrow_owner follows only a parent's actual first expression operand through parens/projection bases, never an index operand, dereference, mutable/raw borrow, call or block. Stable-encode the new source facts and advance index encoding domain. No scope/type/name/hygiene reinterpretation is introduced; original and admitted generated ASTs use the same index.

Literal/aggregate temporary base conversion in initial_place_thunk keeps its existing constant-expression eligibility and existing PromotedPlace runtime checks, but consumes this shared indexed context instead of a separate AST ancestor walker. ValuePath constant preparation consumes the same context before wrapping its ordinary initializer-produced ItemValue in Promotable. Existing Frame item publication, static-place transfer, projection/index evaluation, Borrow, persistent storage and cleanup remain one route. Eliminate the old direct-parent-only Borrow-recipe query and new AST ancestry helper. No new evaluator or special ALL_THE_NUMS/assertion/macro rule; no constant evaluation is performed by the index.

Only reached operand recipes inspect the existing literal subtree once per memoized conversion recipe. Indexed context traversal is O(actual projection ancestry) during source/value preparation, with constant-size node flags prepared once. No source parsing, whole-file searching, BodyIndex copying or global namespace work on installed execution. No memory accounting/caps/fuel/budgets are added. Existing checked index sizes and fallible allocations remain. Cold branches are indexed structurally but never lowered/executed by this change.

Acceptance: unchanged original's complete main must read returned tuple/constant-array refs successfully; unchanged promote_borrowed_field is a separate weaker runtime witness (unreached const initializer not accepted). Existing promotion/Copy/constant/source controls retain their actual scope; four-origin projection matrix is unexecuted and remains a hold. Nominal Drop source completeness, full generic application identity and complete promotion semantics remain independent holds. All eight source review modes inspect common index/recipe/VM join, exact changed symbols and fingerprints; MA001/003/004/005 legacy alternate routes are not authorized by this change. No whole-feature/interpreter/JIT gate closure from a targeted pass.
