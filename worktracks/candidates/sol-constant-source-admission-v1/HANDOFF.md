## Implemented producer

`ConstantSource::capture_prepared(view, definition)` takes an actual immutable PreparedSourceView, validates original hygiene/declaration syntax, reparses against the captured profile/cfg/owning module path, compares the actual outline fingerprint, locates the exact original declaration and its direct owning module member syntax. It preserves DeclarationContext and BodyHandle for every captured const/function. Associated/lexical/generic/generated cases stay prerequisites. Inline module BITS and externally prepared module paths no longer acquire root-only identities. Ordinary parse/evaluate signatures remain compatible and content-only; raw prepared capture has no primitive authority.

`ConstantSourceAdmission::capture_current(db, view, definition, ConstantRequest, byte_limit)` is the private current producer. Requests are Constant, ConstCall(immutable arguments) or ArrayLength(exact source range). It requires exact published DefinitionSource/Header/Body/DeclarationContext, all actual prepared source/compiler inputs, the unique current Value scope certificate and exact reached/direct module Value members, and a separately published Type certificate at the same module/world/epoch. It checks current SourceDependencies, ExpansionEpoch and actual compiler-input membership/fingerprints. Generated/foreign/native/replacement/argument-declaration lanes refuse. No provider, thunk, guest execution, input mutation or guessed imported/prelude lookup occurs.

The Type join mints a private CurrentConstantTypeCertificate from actual CertifiedScope lookup. Only names proved absent in the current Type namespace are permitted as intrinsic primitives. Present/unresolved aliases/members are kept deferred and refuse when the existing primitive() boundary is reached. Cold shadowed declarations do not force header/body type semantics. Existing AST shadow/import/producer checks are retained. Module absence alone is never used as unsealed Type authority. The underlying Type discovery producer must supply its complete admitted namespace/policy contract; this packet never grants library or generated namespace completeness.

`admission.plan()`, `identity()`, `metadata_bytes()`, `dependencies()` and `revalidate(db, view)` are the exact root query-publication APIs. Revalidation compares all current input membership/fingerprints (conservative invalidation on any publication), then remints against the same selected original/request/budget and compares plan/seal/source identities. Derived publication/epoch changes are detected even without source_revision changes. A privately minted proof may be cloned only as immutable evidence; a caller cannot edit its fields or issue primitive booleans.
