# M032 / WT06-05 source and dispatcher prerequisites

The new runtime and VM leaves are **private physical kernels**, not source admission. `construct_closed_box_physical`, `borrow_closed_box_physical`, and `ManagedBoxCleanup::begin_closed_box_cleanup_physical` accept checked storage agreement only. They are not called by ordinary source lowering/step/run. There is no production source-success constructor, dummy proof carrier, spelling dispatch, guessed trait witness or external handle decoder. Ordinary CleanupMachine receives a typed Unsupported for ManagedBox until its owning continuation join is installed. Parent owns that join, source selection, IR/step/run and canonical validation.

Required real producer at the source boundary (currently absent):

1. Replay the actual consumer PreparedSourceView/input universe/query and source epochs, world/seals/profile/cfg/dependencies. Consume the genuine currently published source-library selection with real std→alloc→core edges and owning alloc root. A captured library-file hash is observation data only. The ae0fe511 upstream Box header inspected here is a primary semantic witness, **not** authority for a separately selected live b940/sysroot/native generation.
2. Identify the actual owning `alloc::boxed::Box` declaration and `owned_box` lang-item, its exact definition/schema/type arguments and implicit Global allocator choice from entered declaration/header/catalog proof. Preserve std reexport vs alloc ownership and shadowed/custom Box identities. Retain the true source pointee term and a checked closed primitive or fixed primitive-array layout. Match the actual value's source view to that term before an owning read. A `FacadeType::Box` descriptor is agreement data; interning it grants no source/library permission.
3. For `Box::new`, consume the actual selected member/impl identity (`box_new` defining source header), signature/argument/result substitution and predicates. For operator `*` on the source-owned Box, retain the genuine owned-Box intrinsic projection admission; do not invent a method witness from the descriptor. Explicit Deref/DerefMut member calls/coercions require their actual selected core trait/impl/member goals and dictionaries. Mutable access inherits receiver place/source permissions; immutable Box or shared-ref receivers cannot mint &mut.
4. Bind the reached caller Body/PC, exact macro/ordinary role, span/token origins and effective editions, frame/run epoch, current source view and required dependencies. No arbitrary descriptor/member string/digest/Boolean/“complete” flag may replace these opaque packets. Revalidate after any suspension, changed universe or epoch, before guest read/charge and again at final publication if a source/query boundary intervenes. A typed query/source failure stays a failure, never a guest Box.

Physical join sequence after real source proof:

- Construction: evaluate the already indexed argument once; preserve its exact owning temporary/source view. Pure `preflight_managed_box` validates type/value/owner and complete 3-handle/capacity reservation. One authoritative opcode charge, then reserves and commits a new ManagedBoxRecord + stable heap Cell + result Ticket. The argument ticket moves once into that heap cell; result ticket must initialize an ordinary reserved temporary, with the actual source Box term. Reserve optional destination and retained source/activation metadata in the same parent batch before commit. This packet does not supply Frame source-view admission for Box, general facade argument/result contracts or ordinary Call routing.
- Borrow/deref: run true source/receiver projection proof and existing operand order before `preflight_managed_box_borrow`; use `borrow_closed_box_physical` only after admission. It charges once, reserves lease/ticket, and revalidates actual receiver permission before publication. A shared/mutable ReferenceRecord targets the stable heap cell; array field links retain complete object/variant/child stamps. Ordinary scalar Copy reads can use existing reference read; whole array Copy uses the existing resumable aggregate Copy activation and real source result type, not a duplicated ObjectId. Destructive pointee extraction is deliberately Unsupported for this closed Copy slice, preventing incomplete enclosing summaries.
- Ownership: kind15 is not Copy and cannot acquire a second owner through public `ticket(ValueRepr)` or `copy_from`. Moving the Box's value cell changes its location epoch and its sole transfer owner, **not** the heap cell/epoch. References to the Box value itself stale on that move; references to the pointee remain live through cell/ticket/constructor ownership. No raw pointers or host references are retained.
- Cleanup: source-admit managed Box destruction first; the parent root ticket remains owned by the machine while exactly one child heap location/ticket is Dropping. `ManagedBoxCleanup` performs at most one primitive-array field per advance, charges every field including Unit, and acknowledges exact child destruction before Box retirement. A consumed owning array ticket moved to another location cannot acknowledge destruction: its ObjectId must actually be retired. Cancellation/fuel stop is retained, closed obligations drain without reset/new guest fuel, then Failed(original diagnostic), never Complete. Resource/internal/epoch errors retain `cleanup_pending` and require the driver's fatal reset/teardown if the obligation cannot drain; they are not evidence of successful Drop. General nominal/Drop/dyn/allocator callbacks are refused.
- Shared exhaustive attachments: cell arena construction/reset/ownership/validation, CellOwner::ManagedBox, stable root lease validation, initialization/extraction guards, Facade Box final NonCopy status, constructor acknowledgement for kind15, VM module and ordinary cleanup typed refusal are separately reviewable in runtime-attachments.patch. They must be merged alongside frozen Vec Buffer match arms rather than overwriting their anchor logic.

# IR/cache/capture boundary

No opcode or successor schema is invented here. Existing ValueKind15 and its 16-byte/8-byte-aligned representation are preserved; payload is a typed run-local arena ID. Canonical source capture schema5 and the separately proposed future Vec/schema6 packet remain unchanged. Root must choose uniform Box recipe/operation/exit placement, attach every encoder/decoder/verifier/capture/exhaustive operation dispatch, bind source/member/proof/epoch/dependencies in producer identity and make older cached units miss before enabling ordinary source routing. Never decode a supplied raw Box arena index or use tag15 to choose a library member.
