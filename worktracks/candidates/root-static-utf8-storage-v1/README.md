# Immutable UTF-8 storage candidate

Source-only T024/T041/T062 physical storage draft, LOCAL-024. This five-file extension follows the byte prerequisite, assertion/admission successors and their production import/strict repairs. It is held behind the active byte validation queue. It has not been compiled or executed and adds no upstream runtime passes.

The existing immutable run-owned byte backing can now publish a genuine shared `str` view. Preparation validates UTF-8 before descriptor publication, allocation or writes. Only completion records the string lease in private root membership. A copied descriptor or forged slice view cannot establish that membership. Array, byte-slice and string references have separate cached leases; reuse requires equality with the immutable backing. The same per-byte construction/reuse fuel, bounded dispatch, rollback and run-reset behavior is retained. UTF-8 validation itself is a bounded pure scan with the existing one-MiB cap; no performance or constant-time preparation claim is made.

The byte-literal source mapper explicitly rejects this new physical view: storage shape cannot invent string source authority. This packet does not yet execute a string literal in the VM or authorize `len`, equality, `as_bytes`, `contains` or `include_str!`. Those source/member/VM integrations remain required for the original programs.

Four pending component controls consume actual Unicode/NUL/CRLF tokens from unchanged rustc originals, check exact backing bytes after frame cleanup and run reset, reject malformed UTF-8 and forged views without effects, preserve distinct string/byte leases over the same verified root, and exercise a repeated original Unicode token across dispatch boundaries and cancellation. The repeated payload and invalid-byte controls are disclosed LRR storage regressions, not new language fixtures. Upstream whole-main and full-fixture acceptance remain unexecuted.

Before future validation, add the two Unicode/NUL originals using the normal additive importer if the frozen source lacks them. Preserve its manifest and prior byte imports.
