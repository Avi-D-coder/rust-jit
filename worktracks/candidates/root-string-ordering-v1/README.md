# Source-selected immutable string ordering

T062 follows the unchanged rustc `tests/ui/array-slice-vec/estr-slice.rs`, whose string comparisons include equal prefixes, different leading bytes and all four relational operators. Its eight literal initializer operands are reused through the pinned parser in the new physical control. No upstream source is adapted. Whole-main acceptance remains pending: printing, `as_bytes`, indexing and the remaining required operations must execute too.

The canonical compiler comparison facet now separately identifies shared-str `PartialOrd` and existing `PartialEq` members. Eq/Ne receipts cannot authorize Lt/Le/Gt/Ge; byte array/slice views, mutable str, mismatched profiles and macro-only catalogues cannot acquire this string ordering member. The engine revalidates the exact current source recipe, original PC/operator/slots, source types and physical UTF-8 leases before selecting it. This is the pinned core byte-lexicographic contract, without native std calls or locale ordering.

The equality cursor retains its API and length-short-circuit behavior. A separate string ordering cursor compares at most 256 byte pairs per dispatch with one charge per inspected pair, and uses length only after the common prefix is equal. It checks session, epoch, exact operand/root stamps, committed UTF-8 membership and cancellation. Failure/completion is terminal; admission refuses a partially advanced cursor. The frame retains the physical trait variant through suspension and publishes one Bool after the selected predicate completes. Existing LRIR opcode tags and schema 15 stay unchanged; compiler comparison facet identity advances to `lrr/v3/core-immutable-literal-comparison-facet`.

Four new controls cover the original literal pairs across all editions, source/operator/compiler-member refusal, prefix-versus-length and Unicode/NUL ordering, and bounded continuation/fuel/cancellation/foreign-store refusal. These are unexecuted component and LRR correctness controls, not upstream fixture passes. Exact predecessor hashes, no-fuzz/no-offset replay and Rust 1.99 leaf formatting passed. Strict compilation, guest source/operator execution, existing equality scopes and the integrated milestone remain pending. General borrowed storage, owned String and byte-array/slice ordering remain required future work; no task, full-suite or JIT completion is claimed.
