# Reached context for negative integer locals

T024/T025/T032 invariant: a source-written unsuffixed negative integer local may receive its type from a reached concrete argument context; Rust numeric fallback must not erase that context or cast a previously bound value. The unchanged official `integer-literal-suffix-inference.rs` reproduced `LRR-E-CALL-ARG-TYPE` at line17, `id_i8(j)`, after `let j = -128`. The retained executable had selected i32 while lowering the initializer as an operator. The [actual runtime receipt](../../evidence/2026-10-15-retained-numeric-runtime.json) preserves that failure alongside two separate stock numeric runtime-contract passes. The failing case is not marked passed.

Ordinary lowering already folds this source form into a deferred signed integer literal. Initializer fallback now preserves that record for ordinary value bindings; reference bindings keep their prior route. Source-indexed reads obtain a soft integer fallback recipe only after the exact original untyped let/pattern/initializer is matched inside its owning entered body. The helper checks original body/profile, pattern range, reference/annotation modes, suffix, and bounded parentheses. It does not resolve a callee, query its body, scan future call signatures or execute another operand.

Macro planning binds its finalized step PC and accounts for the boxed proof. Both the verifier and VM replay that admission; a raw pattern ordinal cannot grant it. Its VM operation preserves an existing reached destination context first, then an already-bound local/literal context, and uses the source-proven i32 default only when neither exists. It grants no native, trait, UTF-8 or source lifetime authority. The existing checked scalar materialization performs range/family validation and shared-record unification; a concrete mismatching value is never reinterpreted. Ordinary path and compiler-assertion operand reads use the same policy. Typed locals, suffixed literals, reference bindings and nonliteral operator initializers retain their existing paths.
