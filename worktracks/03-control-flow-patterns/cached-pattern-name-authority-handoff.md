## Root Product allocation ownership prerequisite

LOCAL-024, WT03-02/03, T030/T031/T050/T051/H002/H003. The staged
PatternSourcePlan now owns real Product Arc handles and verified thunk operations
may own those same allocations. SourcePlan-only/body-only pins miss an external

strong count. This can evade retained metadata charging and make last graph
release occur during PatternFinish. Existing unchanged search-via-bindings.rs is
the primary language witness; this prerequisite needs LRR retained-allocation,
shared-handle, invalidation and between-run eviction controls outside originals.

Root extends Database::memo_owners, QueryPin::external, returned and cache_usage.
Count every actual Product handle owned by each distinct inner SourcePlan or
outer boxed recipe. Count each distinct Product's single nested index handle
once. A bounded Product retirement-lease registry survives outer memo retirement;
it grants no source, name, type, pattern or runtime authority. Charge exclusive
Product/control-block and nested index allocations once, separately from source
plan/recipe inline bytes. Retain owning memos while external Product handles
exist. Recompute eviction accounting after each between-run removal instead of
subtracting incomplete guesses about transitive shared ownership.

Cold coordinator accounting may traverse retained memo roots. Installed pattern
execution receives retained products and does not build maps, walk syntax or
capture witnesses. The registry is bounded before mutation; actual product
identity and verifier admission remain unchanged. No new parser, expression or
pattern evaluator, numeric/member rule, origin exclusion, cold-arm demand,
namespace census or immutable-body clone is introduced. Existing legacy routes,
binding proof, production-switch and all MA findings remain held. Source review

Root follow-on review found weak-only registry accounting does not itself prevent
last graph destruction during PatternFinish after source invalidation. The staged
implementation therefore retains one real Arc lease per registered Product,
counts that actual owner, and releases leases only at between-run coordination
when no external owner remains. This replaces the weak-only proposal before
compilation; it is not an accepted feature/performance claim. Graph/control-block
and nested-index bytes remain separately accounted, and no semantic authority is
attached to these retirement leases.
