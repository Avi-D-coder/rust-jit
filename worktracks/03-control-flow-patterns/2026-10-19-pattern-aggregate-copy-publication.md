## Implementation refinement, parent6551f55435, solo

Use one publication continuation for every Expose/Commit, including scalar, reference and move bindings, through existing frame OpActivation. Preflight all transfers and reserve binding storage before publication; then advance each binding in written order. Aggregate binding copies use the existing AggregateCopy worker; completed bindings immediately belong to ordinary frame cells. No guest body/guard executes while publication is partially complete. A failure retains the activation/cursor and any private construction; completed cells remain ordinary scope-owned cleanup obligations. This replaces the synchronous publish_pattern production loop rather than maintaining a second publication route. Keep full fault/cancellation acceptance explicitly held until exercised.

The prior owned-temporary CopyAggregate -> Move optimization is also removed: an @ binding and a nested field binding can both read a Copy scrutinee, so moving its root before the later binding is incorrect. Copy aggregates always use the same fresh graph copier; no speculative overlap check or fixture-specific fast path is introduced. Non-Copy transfers still move. Continuation pins actual owner/solution/tree, PC/operation and binding cursor; no BodyIndex clone, source preparation, global namespace scan, accounting cap or macro identity rule.
