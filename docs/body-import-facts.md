# M007 original import facts in entered bodies

Entered-body discovery now retains enabled use-tree leaves through the existing
pinned AST import collector. Each leaf keeps its lexical block ordinal, original
path/absolute qualification, alias/glob/anonymous kind, visibility, source range,
identity and containing module scope with the exact body definition as owner.
Transforming import attributes retain their producer demand beside the original
syntax facts; they do not publish namespace bindings.

The containing scope comes from the exact selected ItemOutline and BodyKey in
the immutable prepared source view. Import identity uses an explicit stable
encoding of body definition, lexical scope, local occurrence and original tokens.
The collector shares its checked import depth, global leaf and cumulative owned
metadata admission with original item import discovery. The entered traversal
also checks wrapper count and allocation before extending its retained inventory.

Source acceptance covers grouped/raw aliases, self-as-module syntax, nested
blocks, globs, disabled imports, transforming demand and opacity of nested
functions, closures and macro templates. These facts are discovered only in the
explicitly entered body.

Body-local named/module/glob namespace construction and invocation consumption
remain the next integration step. No import lookup, expansion, guest VM or release
acceptance is claimed by this syntax inventory. M007 remains in progress.
