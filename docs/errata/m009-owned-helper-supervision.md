# E-M009-001: bounded owned helper supervision

Section 3.2 called for standard-library process management while M009/MX017 require bounded helper termination, and Section32.2 confines local production unsafe to the five JIT/native files. Rust1.99 standard-library Child::kill kills the owned child without closing pipe writers inherited by a surviving descendant. A blocking protocol reader or stderr drain can therefore outlive the helper deadline. The standard library supplies neither safe nonblocking pipe-flag access nor an owned process-group signal API.

The minimal macOS witness is `standard_child_kill_leaves_inherited_pipe_blocked_until_owned_group_cleanup` in `crates/lrr-expand-adapter/src/proc_client/process_guard.rs`: an owned shell spawns a sleeping descendant, the parent is killed and reaped, and a reader remains blocked for the observed timeout. Signalling only that fixture's separately created process group releases the reader. Cleanup precedes the witness assertion so a failed test leaves no intentional sleeper behind. `artifacts/macos-first/m009-supervisor-unit-tests.log` records the actual passed witness.

Keep std::process::Child, std threads/channels/condvars/timers, and the existing pinned external macro server. Add an exact Rustix1.1.5 fs/process feature dependency; that package/version was already in Cargo.lock. Its pinned source provides safe fcntl_getfl/fcntl_setfl and kill_process_group APIs. A private constructor uses CommandExt::process_group(0), admits only its newly spawned child's positive group ID, and rejects INIT. No caller-supplied arbitrary group can be signalled. Deadline/cancel/exit cleanup terminates the owned group and reaps the direct helper. Nonblocking read/write wrappers also stop at helper termination when an external pipe holder survives. Request and reply byte allowances are independently bounded and reset only between serial operations.

Regression checks cover inherited reader/writer holders, actual procedural macro descendants, native stdout/stderr overflow, cancellation, root exit status and no retry. The descendant's own PID is checked with a signal-zero liveness probe; macOS sandbox denial of /bin/ps is not counted as successful validation. The helper is reaped by its owner; the controlled descendant must disappear before its check passes. Deliberate native group escape is not a hardened containment promise. General malicious protocol/span stress remains M045 and full guest VM/phase checks remain later integration. Linux replay is deferred.

This is a narrow supervision API correction, not a replacement frontend/query/native/sandbox/tiering design. No local production unsafe is added.

M009 span integration additionally exposed a normal-exit/EAGAIN race during parallel helper startup. EOF can arrive after the status observation while another concurrent fork briefly retains close-on-exec descriptors. Interruptible IO allows one fixed 100 ms drain window after normal exit to observe actual bytes/EOF; it never manufactures EOF and never resets the window. Deadline and cancellation exits remain immediate failures. The normal-exit regression exercises delayed EOF and a permanently held peer; the inherited read/write deadline regressions remain required. Failed milestone evidence is retained in m009-span-before-exit-race-gate*.json and m009-span-before-drain-window-gate*.json.
