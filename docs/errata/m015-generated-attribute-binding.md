# E-M015-013: generated attributes bind in their captured declaration grammar

M015/revision 4 sections 49.3/50.2: a generated attribute request must preserve
its exact retained producer and lexical declaration grammar through preparation,
binding, explicit macro execution and record matching. Items is the module-item
slot; generated Statements, ImplItems and TraitItems require their own slots.

The integrated contextual grammar candidate failed the current macOS milestone
at three unchanged generated-cold procedural test catalog controls. Each actual
Statements request failed before the second callback in DeclarationFragment's
attribute binder with the metadata/count limit diagnostic. An independent
private copy reproduced all three failures while two neighboring controls passed.
The binder still hard-coded Items after preparation correctly retained the
selected declaration grammar. The failed milestone, strict tests, source bytes,
source membership and terminal logs are retained; checkpoint 2022 remains the
last completed macOS milestone.

The repair compares request grammar with the retained pending selection's grammar
and includes grammar in selection/request matching. It reports a request mismatch
as LRR-E-EXPANSION-INPUT and reserves LRR-E-DISCOVERY-LIMIT for the actual retained
metadata/count bounds. It preserves ordinary module Items, procedural form checks,
producer identity, explicit authority and all checked allocation limits. No guest
runtime compilation or arbitrary native loading is introduced.

The five unchanged baseline controls passed after the repair with source bytes
and membership fixed. Joint private validation passed library194/adapter30,
declaration_scan67/source_discovery61, four unchanged actual Attribute callbacks
across original/local/trait/decorated controls, the three associated-slot controls,
format and strict Clippy. An independent macro-generated trait reproduced the
exact TraitItems binding failure before the repair, then passed unchanged with
one actual MBE parent and one procedural callback/record after the two exact file
copies. Parent independently passed both source/native controls. The empty current
root catalog, rootfoo absence, repeated reads/filters and body/signature/thunk0
were exercised; no child Scope seal or fabricated member identity is claimed.
