# E-M015-001: physical generated roots and insertion attachment

The specification keeps the actual expansion grammar and exact source member
identity. The implementation previously required every generated physical root
to equal its producer insertion kind. An admitted Expression expansion containing
a block with a module has physical root Unattached under original Block insertion;
its module belongs to a nested generated Block. The retained witness and regression
show the old unconditional guard rejecting this valid owned capture.

The matched-record companion checks the exact producer grammar, uses the scanner's
physical root kind for non-Items slots, and preserves nested generated lexical keys.
Only an Items-shaped capture inherits the insertion kind. A header-only argument
capture has no matched output grammar and retains its existing conservative API.
Owned module admission checks expected epoch and derives normalized context from
pinned owned facts, retaining unproven annotations and granting no route or seal.

The component passed 173 library/64 scan/7 enclosing controls, formatting, strict
workspace Clippy and architecture. This does not prove namespace caller wiring,
module route publication, full stock/M015/guest/JIT/release/Linux acceptance.
