# H003 component acceptance and required integration

The H003 current component consists of immutable reached-pattern binding modes,
source-backed scalar condition modifier checks, compiler-owned async trait routes
in the ordinary namespace graph, identity-based execution refusal, and explicit
unsupported generator inventory. The actual native E2408 baseline and edition pair
remain native-only observations. This is provisional component acceptance under
Section57/E-57-001, never complete edition-gate or release acceptance.

DefaultBindingMode is Move/Ref/RefMut. Reached shared/mutable peeling and explicit
modifier/reference checks preserve edition2024 restrictions and older source
edition behavior. Their stable context identity includes edition and mode. Scalar
binding shadowing and cold reference clauses use the actual source VM. General
reference/aggregate matching, pending bindings, non-consuming arm tests and commit
are not implemented by this component; they require T050/T051/M028.

Async trait reservations include the Rust1.99 v1 AsyncFn family and the 2024
Future/IntoFuture additions. Core/std qualified and prelude aliases preserve one
canonical identity. Shadowing, pending producers, namespace separation and exact
provenance admission are exercised through the ordinary name index. The facade
execution guard produces LRR-E-FEATURE-ASYNC when an async identity is selected.
M025/M026 must integrate those reservations and the guard into complete source
member candidate selection, including ambiguity with glob-imported methods.

M014/M016 must supply generated/dependency token editions to pattern/prelude
selection. M025/M028 and T050/T051 must exercise reached versus unvisited prohibited
patterns with actual references. T060–T065 complete the facade/type inventory.
T080/T084 and M035/M037 must supply forced-JIT/cache equivalence. M043 must run the
full E2408 and edition collision matrix with actual LRR observations; T104 must
require the complete edition2024 gate. No pending fixture is a skipped pass.

The ledger retains E2408 and the complete executable async-facade integration as
pending, with release_complete=false. The full prior pattern suite currently
available is included in the macOS milestone gate; it does not prove a future
aggregate/reference pattern suite exists. All final acceptance requirements and
the macOS-first/Linux-later platform sequencing remain unchanged.
