# M013 nested and generated compiler includes

M013 remains in progress. Generated item-position calls now select the configured
compiler facet through the existing textual/path/hygiene resolver, retaining exact
builtin identity instead of looking for a declarative body. The CLI dispatches both
original and generated compiler demands through explicit capture, coordinator
start/accept/adopt and output reproduction. Ordinary expansion/admission refuses
compiler requests, including generated requests.

The frontend only prepares immutable lexical context. Discovery runs the existing
bounded eager compiler worklist with a resolver for the generated lexical world.
An argument snapshot omits its own invocation position while retaining earlier
producers. Nested compiler string operands use actual owned tokens, source edition,
hygiene and exact definition selection. A user-defined concat remains an ordinary
macro requiring explicit argument expansion; this checkpoint does not implement it.

Adopted syntax includes retain source views certified against the exact captured
record, reproduced producing expansion and nested path producers. Views keep the
containing-file spelling, capture origin, content and owning root authority.
Subsequent included calls use that retained view, validate its immutable inputs and
request capture relative to the included file. Metadata is checked and charged.
Generated fragment completion includes every observed compiler input in the seal,
so publication refuses missing/stale inputs instead of certifying partial discovery.

Fourteen new controls cover nested literal/concat paths, three-file chains, generated
includes and substituted path arguments, disabled preludes, local include shadowing,
missing/malformed source, symlink escape, ordinary/forged admission and stale seals.
Six CLI programs compare actual values with isolated native macOS ARM64 Rust1.99.0
copies. An initial seal-membership bug and frontend/service layering violation were
caught and corrected; their failing evidence is retained. Earlier checkpoint hashes
remain historical snapshots rather than claims about current files.

General mixed-source/cross-unit generated-token paths, generated macro body include
contexts, multiple source/build-output roots, user/procedural string operands,
compile-expression runtime lowering, full Cargo/environment/unit/world facets,
module/origin/quota/runtime/type integration, M014–M016, full MX027/MX028/JIT and
release acceptance remain mandatory. Linux remains a later port. These controls
provide component evidence without marking M013, full fixtures or release complete.
