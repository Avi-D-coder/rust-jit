# M013 generated fragments in captured external modules

M013 remains in progress. Generated lookup now borrows a captured macro context:
the actual active source, its frozen original call position, and the immutable
captured owner catalogue. The existing resolver combines generated ancestry with
source outer scopes and actual external parent declarations. Current parent facts
include completed earlier expansions; later declarations remain invisible.

Qualified generated candidates use all captured source routes, and requests find
the actual source/generated owner by full selected definition identity. Exact
request key, input tokens, span context and editions remain validated by the
existing immutable request builder. Parent/index/record references are borrowed;
requests retain owned captured bodies. No files or tools are opened by providers.

Completed generated root/child import routes keep the same captured context.
When a fragment completes, its macro facets are installed into the closed name
graph before import resolution. A later original macro call is no longer needed
to trigger that publication. Route catalogue counts and metadata are checked.
Partial generated routes remain candidates, not negative query certificates.

Nine controls cover inherited generated calls, qualified sibling owner bodies,
generated parent imports, nearest external parents across nested expansions,
completed generated parent bindings, future-parent refusal, generated imports
used by later original calls, child route snapshots and completed textual import
sealing without a later original macro call. Five baseline cases failed before
integration. All positive controls execute actual generated functions in the
existing tagged VM.

Pending work includes complete macro namespace query certificates,
dependency/definition-unit routing and overlapping origin cases, runtime macro
contexts, symbolic type/alias integration, complete quota/failure boundaries,
full MX027/MX028 CLI fixtures and E24/release acceptance. These component tests
run first on macOS ARM64 Rust 1.99.0. Linux support remains unverified.
