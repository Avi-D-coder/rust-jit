# M013 standalone CLI discovery integration

M013 remains in progress. `lrr run` now captures the external module source contexts
from the approved immutable snapshot, runs actual declarative fixed-point discovery,
and publishes the completed graph/records/certificate before starting guest execution.
Expansion is an explicit coordinator step; query providers do not run matchers or tools.
Only captured source bytes are used for module selection after initial disk capture.

Module requests preserve logical module suffixes independently of physical directories
and path attributes. Source contexts, module queues, depth and retained metadata are
bounded. The existing module_target function retains path/ambiguity checks. All source
views share the same immutable publication. Cold ordinary body errors remain unprepared.

Runtime compiler macro lookup replays original item producers from actual completed
catalogues into a new published index. Full source/context/publication identity is
checked. Generated macro shadowing cannot silently fall back to a compiler intrinsic.
The discovery object and its original completed indexes remain unchanged.

Eleven actual CLI controls cover a generated import plus later-needed macro, originating
cyclic reexports, unresolved producer/import cycle refusal before execution, external
parent body selection, path/logical identity, cold generated bodies, expansion failure,
post-expansion assertions, inline path directories and generated builtin shadowing.
A valid MX027 source fixture also executes under the CLI interpreter and an explicitly
prepared isolated Rust 1.99.0 native oracle. Raw version/compiler/native/CLI output is
retained under artifacts/macos-first/m013-cli-oracles. The selected live unit is never
compiled or loaded. Four initial CLI cases failed before integration; one unresolved
cycle incorrectly completed main before the fix. The existing selected attribute
control now expects catalog-incomplete rather than the earlier generic unsupported
classification, still with nonzero exit and empty stdout.

These are interpreter CLI component controls. Full MX027/MX028 fixture matrix/JIT modes,
generated test catalog (M015), generated main selection, generated-body runtime macro
contexts, complete dependency/definition-unit and origin integration, type paths and
quota/failure boundaries remain pending. Original test CLI integration is retained;
generated tests remain a later ordered task. No full fixture/release/Linux claim is made.
Validation is macOS ARM64 with Rust 1.99.0 first.
