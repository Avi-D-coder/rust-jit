# M013 later-group member helpers and introduction positions

An enabled member annotation can use an exact bare helper declared by a later
derive group on the same original item. When current/preceding metadata does not
establish that helper, discovery demands the later group's exact declaration
receipts before selecting native execution. It does not grant a qualified helper
path or use a helper from another item. Known current-member scopes retain the
existing ordered queue; unrelated unresolved later groups are not required merely
to select an earlier derive whose member annotations are already classified.

The source group-row resolver is shared by ordinary selection and lookahead. It
preserves the existing source/producer/group/occurrence identities, ordered paths,
catalog/definition checks and exact declaration receipt validation. The local helper
scope deduplicates receipts and records each introduction index and source context,
with checked receipt-count/metadata limits. Native selections bind the receipts
used to classify their input; completed selections and source completion proofs
retain their replay checks. Metadata lookahead invokes no native macro.

Outer annotations still require a preceding introduction. Later-group metadata
that makes a field helper inert does not make an earlier outer annotation inert.
That outer case remains typed incomplete; complete legacy ordering diagnostics
and lint policy remain pending. Helper names introduced by both groups may still
be used between them because the first introduction is sufficient.

The member controls adapt the unchanged copied `derive-helper-configured.rs`
outside its licensed directory. They insert a first derive with no helper exports
and retain the later derive that declares the field helper. The first controlled
macro checks that its group was removed, the later group remains, and both helper
annotations remain in the actual input. Two declaration receipts are required
before its selection; two native derives then complete and publish real constants.
Qualified-member and early-outer variants retain explicit zero/one-invocation
incomplete outcomes respectively, with publication refused.

The unchanged official `helper-attr-compat-collision.rs` is newly imported with
its auxiliary, directives and original licenses/hashes. Its adaptation selects two
controlled exports declaring the same helper. They execute in order, retain the
intervening helper, and seal/publish. This matches the stock fixture's introduction
ordering shape; it does not execute the original rustc auxiliaries or accept a full
stock fixture. The import manifest now contains twelve cases and thirty files at
