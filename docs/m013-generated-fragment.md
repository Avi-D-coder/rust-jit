# M013 generated-fragment call scheduling interface

GeneratedMacroCatalog::for_discovery admits known root item-call frontiers while
preserving the strict constructor's incomplete-producer refusal. Captured cfg is
applied through the existing owned syntax outline before calls enter the queue.
Attributes, external modules, nested producers and damaged declaration boundaries
remain incomplete. Active calls map to exact owned token facts and canonical header
identities; the queue follows source offsets with stable identity tie-breaking.

next_call uses the existing TextualScopes, MacroDeclarations, pinned HygieneFacts
and explicit expansion origin. A preceding unresolved call blocks later selection.
A ready bare-name selection creates an immutable GeneratedCallRequest with the
selected definition, actual input wire digest, call-site context/edition and frozen
parent compile-environment/engine identity. Repeated polling shares that demand.
Qualified or unknown paths remain NeedInput; no absent export is certified.

Only explicit request expansion runs the pure pinned matcher. Completion requires
an exact-key immutable record and checks grammar/epoch and cumulative retained
wire/allocation/header budgets before publication. Output with imports, macros,
modules, impls, traits, transformations or further producer frontiers remains
catalog-incomplete until nested integration. A complete leaf output closes only
that textual call frontier, retains its record and returns the generated items to
the coordinator. This interface does not publish namespace or global declaration
seals. Outward publication refuses catalogs with outstanding calls.

Five controls exercise actual generated tokens and matcher output: same-fragment
selection with a real generated function and literal; cfg filtering before scheduling;
a preceding unknown call blocking later work; wrong-reply refusal without demand
loss; and ordered repeated completion with further generated producers remaining
incomplete. Strict original/source-discovery behavior remains covered by prior controls.

scope chains, integrate recursive child outputs and generated bindings/imports, handle
qualified/contextual paths and definition-unit routing, publish query inputs/seals,
and complete quota/failure boundaries and full MX027/MX028. Nested declaration scans
remain M014 work. No full LRR fixture or release claim is made. Validation is macOS
ARM64/Rust 1.99.0; Linux remains deferred.
