modules deterministically, checks declaration syntax and pairs each original
outline with the existing namespace/source proof. Cfg has already been applied by
capture. The ordinary NameNamespaces import fixed point resolves the actual source
imports; its pending, missing, inaccessible and ambiguous imports remain unresolved
work rather than becoming successful absence.

Source jobs register actual header identities and complete outline fingerprints.
Import jobs are discharged only by the existing resolver's resolved list. Unknown
item/attribute producers block discovery; captured external module sources can
discharge their exact module-input frontier. A requested scope can publish a seal
only after all required captured jobs complete. Lookup is read-only and unavailable
before sealing; the mutable namespace graph never escapes.

a macro-blocked generated import, inactive cfg producers, cold invalid type/call
bodies and source edits that change the seal even without changing a selected name.
No cold body is executable-lowered by this pipeline. These are actual source/import
controls, not full MX027/MX028 generated expansion fixture passes.

The scheduler's ready and blocked indexes avoid repeatedly scanning completed job
prefixes. Preflight validation precedes direct delta commit, so completed work does
not copy the whole catalog. Blocking accounts for the retained vector capacity.
A 10000-job regression exercises reverse enqueue and ordered completion. No broad
performance target is claimed from that test.
