M013 remains in progress. The eager driver follows the actual nested invocation
returned by each adopted expression output rather than selecting its original
operand again. Missing outputs remain explicit demands; only the coordinator
adopts them. The pure worklist never executes source or procedural macros, reads
files or captures ambient environment. Each producer key and output remains in
the include argument proof and is re-observed before routing and view admission.

Returned token contexts are normalized by the pinned adapter HygieneStore and
merged with existing owned facts. Captured source uses the retained invocation
position; generated source retains its existing scope/outer-scope chain and call
position. Compiler child frames inherit the facts. Include-view reproduction uses
the same bounded chain, avoiding a separate single-output reconstruction. Checked
metadata and depth limits cover the chain and its retained contexts.

generated scopes, invocation-file paths, user concat shadowing, absent macros,
non-string refusal, explicit adoption before capture, changed compile environment
and discovery seals. Five isolated native macOS ARM64 Rust1.99.0 programs compare
successful values directly. The baseline two-test process was confirmed live,
then interrupted with exit130 after both tests exceeded60seconds. Its original log
is retained; it is neither a passing test nor a completed failing-test result.
