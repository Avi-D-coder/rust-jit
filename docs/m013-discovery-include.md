# M013 compiler-input include discovery

M013 remains in progress. Explicit compiler-facet configuration joins the existing
source macro route graph and scoped compiler prelude. Ordinary textual/path
selection still chooses the definition: a source macro named include can shadow the
compiler export. A compiler request retains exact original call tokens, source
publication, lexical scope, owning edition and a bounded argument index snapshot.
Argument lookup omits the current invocation's pending/output position because its
arguments precede its generated bindings; the actual discovery producer remains open.
Nested macro lookup uses the shared invocation/prelude route engine.

Ordinary request expansion and ordinary record admission refuse compiler demands.
The dispatcher explicitly polls the existing eager compile-input driver. Missing
frozen unit environment or source capture remains typed suspension; coordinator
capture/output adoption is required. Compiler admission reproduces the pure output
from adopted input before allowing the existing generated item/header/macro pipeline
to discharge the producer. This runs no filesystem capture or external tool from a
query. Explicit preparation can attach a frozen environment to its captured root;
its immutable source publication is copied under checked metadata accounting.

Compiler input stamps are retained as deterministic typed keys with checked counts.
The current captured compile-input universe is conservatively bound, including unit
environments, include records and adopted nested expansion records. Those stamps
join the worklist's dependency set and its owned discovery input. Publication checks
current values and exact certificate membership; query validation observes the same
inputs. The discovery-input encoding uses a new owned domain for the added field.
A certificate cannot be republished against changed compile input with unchanged
source. Captured records themselves remain immutable within their generation.

Nine controls cover direct and nested concat includes, generated headers and macros,
source shadowing with zero captures, missing environment suspension, ordinary/
premature/forged output refusal, stale environment publication and real included
function guest execution. The guest result matches an isolated Rust 1.99.0 macOS
ARM64 native oracle; no selected live runtime unit is compiled by LRR.

Compiler discovery currently requires an explicitly configured facet, a captured
unit environment and one source root in the supplied include authority (additional
build-output roots remain supported). Per-unit compile environments, compiler calls
inside generated include output, nested include source views and multiple original
source roots need further integration. CLI preparation, full procedural/native world
facets, mixed-origin editions, origin/invalidation/quota/runtime/type requirements,
full MX027/MX028/JIT, M014–M016 and release acceptance remain pending. Linux is deferred.
This is component evidence, not complete M013 or release acceptance.
